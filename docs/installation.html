Instalación del proyecto

Pasos de cómo se debe configurar e instalar GOML. Copia cada bloque y síguelos en orden.

1. PostgreSQL 2. npm 3. Usuario 4. Certificados 5. Carpeta certs
$ sudo -u postgres psql postgres=# CREATE USER goml WITH PASSWORD 'goml_psw';
CREATE ROLE postgres=# CREATE DATABASE goml_db OWNER goml; CREATE DATABASE $ npm install added 152 packages $ node admin/install.js Instalando GamesOnMyLAN...
Usuario propietario creado correctamente. $ node admin/generate_cert.js Generando certificados...
Certificados generados correctamente. $ mv certs /ruta/al/proyecto/ La carpeta certs debe quedar en la raíz del proyecto, al mismo nivel que app.js.
